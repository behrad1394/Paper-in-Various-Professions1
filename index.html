کاغذ در شغل‌های مختلف

ببینیم افراد در شغل‌های گوناگون چه استفاده‌ای از کاغذ می‌کنند.

📸

عکاس

عکاس از کاغذ برای چاپ عکس‌ها، چاپ رسید سفارش‌ها و بسته‌بندی عکس‌ها استفاده می‌کند.

🏦

بانکدار

در بانک برای چاپ رسیدها، فرم‌های بانکی، قراردادها و اسناد مالی از کاغذ استفاده می‌شود.

🎒

دانش‌آموز و معلم

برای نوشتن تکالیف، امتحان‌ها، کتاب‌ها، جزوه‌ها، برگه‌های تمرین و نقاشی از کاغذ استفاده می‌کنند.

🧵

خیاط

خیاط برای کشیدن الگوی لباس، طراحی مدل‌ها، ثبت اندازه‌ها و یادداشت سفارش مشتری از کاغذ استفاده می‌کند.

🐔

مرغدار

برای ثبت تعداد مرغ‌ها، میزان تخم‌مرغ، مصرف خوراک و اطلاعات مربوط به نگهداری مرغ‌ها از کاغذ استفاده می‌شود.

🥖

نانوا

نانوا از پاکت‌های کاغذی برای بسته‌بندی نان و از کاغذ برای ثبت سفارش‌ها و حساب‌وکتاب استفاده می‌کند.

👨‍⚕️

پزشک

پزشکان برای نوشتن نسخه، ثبت پرونده بیماران، درخواست آزمایش و یادداشت اطلاعات پزشکی از کاغذ استفاده می‌کنند.

💊

داروساز

در داروخانه از کاغذ برای چاپ برچسب دارو، رسید خرید، نسخه‌ها و برگه‌های راهنمای دارو استفاده می‌شود.

🏗️

مهندس ساختمان

مهندسان برای رسم نقشه، طراحی ساختمان، محاسبات، یادداشت اندازه‌ها و تهیه گزارش از کاغذ استفاده می‌کنند.

⚖️

وکیل

وکیل‌ها برای تنظیم قرارداد، نوشتن دادخواست، چاپ اسناد و نگهداری پرونده‌های حقوقی از کاغذ استفاده می‌کنند.

📰

خبرنگار

خبرنگاران برای یادداشت مصاحبه‌ها، تهیه گزارش، چاپ روزنامه و ثبت اطلاعات خبری از کاغذ استفاده می‌کنند.

📦

فروشنده

فروشندگان برای چاپ فاکتور، رسید خرید، برچسب قیمت و بسته‌بندی کالاها از کاغذ و مقوا استفاده می‌کنند.

✉️

کارمند اداره پست

در اداره پست از کاغذ برای ثبت نشانی، چاپ برچسب مرسوله، رسید ارسال و فرم‌های پستی استفاده می‌شود.

🍰

قناد

قناد برای بسته‌بندی شیرینی، جعبه‌های مقوایی، ثبت سفارش کیک و نوشتن فهرست مواد اولیه از کاغذ استفاده می‌کند.

🚕

راننده و شرکت حمل‌ونقل

برای ثبت بار، نوشتن نشانی مقصد، صدور رسید و نگهداری مدارک مربوط به حمل کالا از کاغذ استفاده می‌شود.

🌾

کشاورز

کشاورزان برای ثبت زمان کاشت و برداشت، هزینه‌ها، میزان محصول و برنامه‌ریزی کارهای مزرعه از کاغذ استفاده می‌کنند.

🍽️

رستوران‌دار

در رستوران از کاغذ برای چاپ منو، ثبت سفارش مشتری، صدور فاکتور و بسته‌بندی غذا استفاده می‌شود.

🔬

پژوهشگر

پژوهشگران برای یادداشت مشاهدات، ثبت نتایج آزمایش‌ها، رسم نمودار و نوشتن گزارش‌های علمی از کاغذ استفاده می‌کنند.

♻️ کاغذهای باطله را جداگانه جمع‌آوری کنیم و به مراکز بازیافت تحویل دهیم.
با مصرف درست کاغذ، به حفظ درختان و محیط زیست کمک می‌کنیم. 🌱
